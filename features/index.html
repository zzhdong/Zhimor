FEATURES / YOUR LIBRARY

不止翻页，
更懂阅读。

自定义章节标题、双排与竖排阅读是知墨的重点能力；同时兼顾书库、阅读记录与数据管理。

SIGNATURE READING

阅读形态，由你选择。

横排、双排、竖排和章节标题不只是选项名称，而是知墨专门实现的阅读布局与设计能力。

01 / DOUBLE COLUMN

双排阅读

正文左右分栏；可设置栏间距、中缝分隔线的样式与宽度。屏幕尺寸或阅读状态不适合时会回到单页。

02 / VERTICAL TEXT

竖排阅读

支持文字从上到下、列从右到左的排版及相应的翻页方向；不同文件和阅读情境存在适用条件。

03 / CHAPTER DESIGN

自定义章节标题

使用预设或自建章节标题样式，编辑字体、布局、HTML/CSS 并预览；可导入导出样式。

01 / FEATURE

个人书库与多格式文件

导入自己合法持有的书籍，整理书架、分组与封面。覆盖 TXT、EPUB、MOBI、AZW、AZW3、AZW4、PRC、PDB、uPDB、PDF、DOCX、RTF、Markdown、CBZ、CBR 及 ZIP、RAR、7Z 等相关文件。部分格式通过转换或解压处理，并不代表所有文件均可原生无损显示。

02 / FEATURE

双排阅读与布局细节

在适合的阅读模式和正文宽度下，将文字分为左右两栏。提供可调栏间距、中缝实线或虚线、线宽、高度与透明度。宽度不足、滚动模式或朗读等不兼容状态下，阅读器可能自动回退单页。

03 / FEATURE

真正的竖排文字

支持传统的纵向排字：文字从上向下，列从右向左，翻页方向随之调整。区别于仅把设备转成竖屏；实际支持情况与书籍、正文模式和阅读状态有关。

04 / FEATURE

章节标题的个性化设计

独立的章节标题管理中心提供内置与自建样式、可视化画布、元素布局调整、字体设置、浅色和深色预览，以及 HTML/CSS 模板编辑、样式导入和导出。电子书原有标题可以按相应阅读设置保留。

05 / FEATURE

阅读外观与翻页操作

设置阅读字体、字号、行距、段落、边距、主题与背景，选择横排、翻页效果或滚动方式，调整点击翻页区域。某些选项仅适用于文本阅读引擎和特定阅读状态。

06 / FEATURE

书签、笔记与文字工具

记录书签、划线、笔记与摘录；支持正文搜索、文本替换、字典规则以及按需朗读等工具。功能行为取决于当前书籍类型。

07 / FEATURE

漫画、PDF 与媒体阅读

针对漫画、PDF、音频与视频设置独立阅读模块。可以在同一个书库里管理不同类型的内容，但各类文件的阅读控制与格式兼容性并不相同。

08 / FEATURE

阅读统计与阅读目标

查看阅读时长、进度、完成情况、阅读趋势、按书籍及章节汇总的统计、阅读方式和个人阅读目标。部分统计需要开启相应记录。

09 / FEATURE

导入、网络存储与数据保护

通过系统文件导入、分享扩展和局域网 Wi-Fi 传书管理文件。可选 WebDAV、FTP、SFTP、SMB、OPDS、百度网盘、阿里云盘；iCloud 同步与独立 rbak 备份恢复承担不同的数据管理用途。
