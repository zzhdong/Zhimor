FEATURES / YOUR LIBRARY

不止翻页，
更懂阅读。

从书籍管理、专注阅读到统计、导入与数据保护，了解知墨提供的实际功能。

01 / FEATURE

个人书库与多格式阅读

导入自己的书籍，整理书架、分组与封面。支持 TXT、EPUB、MOBI、AZW、AZW3、AZW4、PRC、PDB、uPDB、PDF、DOCX、RTF、Markdown、CBZ、CBR 及相关压缩文件；不同格式可能通过解析、转换或解压方式处理，并非全部原生渲染。

02 / FEATURE

阅读外观与文字工具

自定义字体、字号、行距、主题、翻页及滚动方式；支持正文搜索、书签、笔记、摘录及文本替换、字典规则等工具。实际排版受书籍内容影响。

03 / FEATURE

漫画、PDF 与其他媒体

除文字阅读外，还有漫画、PDF 的专用阅读界面；音频与视频文件由独立阅读模块处理。不同文件类型的控制与能力有所不同。

04 / FEATURE

阅读进度与统计

跟踪阅读时长、进度、完成情况、阅读趋势等信息，支持查看书籍维度的统计与阅读目标。

05 / FEATURE

多种书籍导入方式

使用系统文件导入、分享扩展或局域网 Wi-Fi 传书。也可按需连接 WebDAV、FTP、SFTP、SMB、OPDS、百度网盘与阿里云盘；支持情况依赖服务端、账号授权与网络环境。

06 / FEATURE

iCloud、备份与朗读

可选择启用 iCloud 数据同步；另有独立的本地数据备份与恢复机制。TTS 朗读需要相应的语音能力或网络服务支持。
