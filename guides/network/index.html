GUIDE / NETWORK

连接云盘与网络书库

自主连接你拥有权限的网络文件来源。

← 所有指南

01

选择合适的连接类型

在“我的云盘”中选择适合服务端的类型，例如 WebDAV、SMB、SFTP、FTP 或 OPDS。提供服务端要求的地址和必要的认证信息。不同协议支持的文件操作不完全相同。

02

连接第三方云盘

百度网盘、阿里云盘需按其授权界面登录或确认权限。知墨不会要求先注册独立的知墨账号。第三方服务可用性取决于服务提供方。

03

排查连接失败

核对主机地址、端口、网络、证书与登录信息，确认服务端允许当前设备访问。FTP 及普通 HTTP 连接可能无法提供与加密协议同等级的传输保护；优先使用可信网络和加密方式。

04

注意内容来源

知墨是阅读与书库工具，不提供或保证第三方图书内容。请只连接你有权访问的文件与服务。

还需要帮助？

提供设备型号、系统版本、知墨版本与操作步骤；不要发送密码、令牌或私人书籍内容。
