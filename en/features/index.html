SIGNATURE READING

A reading layout that suits you.

Two-column pages, vertical text and custom chapter headings are purpose-built reading options.

01 / DOUBLE COLUMN

Two-column reading

Split body text into two columns and customise the gutter and divider. Falls back to single page when the layout is unsuitable.

02 / VERTICAL TEXT

Vertical writing

Read top-to-bottom text in right-to-left columns with matching page direction, where the format and reading mode support it.

03 / CHAPTER DESIGN

Custom chapter headings

Choose or design heading styles, preview fonts and layouts, edit HTML/CSS and import or export styles.

01 / FEATURE

Personal library and file formats

Organise your own lawfully obtained books with shelves, groups and covers. Support includes TXT, EPUB, MOBI, AZW, AZW3, AZW4, PRC, PDB, uPDB, PDF, DOCX, RTF, Markdown, CBZ, CBR and related ZIP, RAR and 7Z files. Some formats require extraction or conversion; native lossless rendering is not guaranteed.

02 / FEATURE

Two-column reading

Split text across two columns when the display and reading mode allow it. Adjust the gap, solid or dashed divider, line width, height and opacity. In narrow, scrolling or listening states, the reader may fall back to a single page.

03 / FEATURE

True vertical writing

Traditional top-to-bottom text in right-to-left columns, with matching page progression. This is actual vertical typography, not portrait screen orientation. Compatibility varies by publication and mode.

04 / FEATURE

Design your chapter headings

A dedicated chapter-heading centre includes built-in and custom styles, a visual canvas, movable elements, fonts, light/dark previews, HTML/CSS templates, and style import/export. Where applicable, you can preserve an ebook publisher's original headings.

05 / FEATURE

Typography and page interaction

Fine-tune fonts, text size, line and paragraph spacing, margins, reading themes, backgrounds, page turns, scrolling and tap zones. Some options are specific to text formats and supported reading states.

06 / FEATURE

Bookmarks, notes and text tools

Capture bookmarks, highlights, notes and excerpts, search within books, use text replacement or dictionary rules, and choose supported text-to-speech tools. Behaviour depends on the current file type.

07 / FEATURE

Comics, PDFs and media

Dedicated reader modules for comics, PDFs, audio and video files. Manage varied content in one library, while file compatibility and controls differ between reader engines.

08 / FEATURE

Reading insights and goals

Review reading time, progress, completion, trends, book and chapter statistics, reading modes and personal goals. Some metrics depend on enabling reading records.

09 / FEATURE

Import, storage and data control

Bring files in via Files, sharing or local Wi-Fi transfer. Optionally connect WebDAV, FTP, SFTP, SMB, OPDS, Baidu Netdisk and Aliyun Drive. iCloud sync and separate encrypted rbak backup/restore serve different purposes.
