GUIDE / BACKUP

Backup and restore

A separate export and recovery process from iCloud.

← All guides

01

Export a backup

Open Data Backup, select the content groups you wish to include and review the estimated size. Export the file to a location you control.

02

Understand the file

Zhimor uses the rbak format with encryption and resource integrity checks. Successful restoration also depends on file integrity, version compatibility and selected data.

03

Check before restoring

Import an rbak file through Data Backup and review the preview and restore strategy. Understand merge versus replacement before proceeding.

04

Keep an independent copy

Before upgrades, device changes or major library reorganisation, retain a tested backup. iCloud sync and manual backups serve different purposes.

Still need help?

Include your device, OS, app version and steps to reproduce. Never send passwords, tokens or private books.
