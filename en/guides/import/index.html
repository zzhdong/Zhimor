GUIDE / IMPORT

Import and organise books

Bring your own books in from Files, sharing or a computer.

← All guides

01

Import from Files

Use Zhimor's import option to choose a file through the iOS or iPadOS file picker. Processing time depends on the file and its source.

02

Share from another app

Select a file in Files or another compatible app, then use Share or Open in to choose Zhimor. If it is unavailable, save the file to Files first.

03

Transfer over local Wi-Fi

Connect your device and computer to a trusted local network. Start Wi-Fi transfer in Zhimor and use the address displayed in the app. Stop the service after transfer; other devices on the same network may reach the transfer page.

04

If a file will not open

Try an intact, unencrypted copy of a common format. Archives may need extraction, some files require conversion, and DRM or unusual layouts may not work.

Still need help?

Include your device, OS, app version and steps to reproduce. Never send passwords, tokens or private books.
